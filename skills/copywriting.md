# Copywriting

## Purpose

Create concise, persuasive marketing copy that supports the strategy and fits the channel.

## Use When

- A campaign needs headlines, CTAs, ad copy, page copy, or email snippets.
- Existing copy is unclear, too long, or off-brand.
- Multiple message angles need to be explored.

## Required Inputs

- Objective
- Audience
- Offer
- Tone of voice
- Channel
- Character or layout limits
- Claims that must be included or avoided

## Process

1. Identify the user motivation.
2. Write the benefit in plain language.
3. Add proof or specificity.
4. Choose a CTA that matches the action.
5. Tighten the copy for the channel.

## Output Format

- Message angle
- Headline options
- Supporting copy
- CTA options
- Notes on tone and risk

## Quality Checklist

- State the benefit clearly.
- Use audience language.
- Remove unnecessary words.
- Keep the CTA direct.
- Avoid vague superlatives without proof.
- Make the next action unmistakable.
