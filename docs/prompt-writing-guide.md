# Prompt Writing Guide

Prompts in this repository should help AI agents produce practical marketing design outputs.

## Prompt Principles

- Give the AI a clear role.
- Include the brief, strategy, channel, and constraints.
- Ask for a structured output.
- Require assumptions and open questions when context is missing.
- Ask for risks, not only ideas.

## Recommended Structure

1. Role
2. Context
3. Task
4. Required output
5. Constraints
6. Quality bar

## Example Pattern

```text
You are a [ROLE].

Using this context:
[CONTEXT]

Create [OUTPUT].

Return:
- [FIELD]
- [FIELD]
- Assumptions
- Open questions

Prioritize [QUALITY BAR].
```
