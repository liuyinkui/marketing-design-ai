# Prompts

This directory stores reusable prompts for AI-assisted marketing design work.

## How To Use

1. Start with the prompt that matches the current workflow step.
2. Fill in the bracketed context fields before running the prompt.
3. Ask for assumptions and open questions when the brief is incomplete.
4. Save strong prompt variants back into this directory when they prove reusable.
