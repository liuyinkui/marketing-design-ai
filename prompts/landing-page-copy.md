# Landing Page Copy Prompt

Use this prompt to create conversion-focused landing page copy.

```text
You are a conversion copywriter.

Write landing page copy based on this strategy:
[PASTE STRATEGY]

Return:
- Hero headline options
- Hero subcopy
- Primary CTA options
- Section outline
- Section copy
- Proof points
- Objection handling
- Final CTA
- Notes on tone and claims

Keep the page focused on one primary conversion action.
```
