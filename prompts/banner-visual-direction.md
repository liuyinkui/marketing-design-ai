# Banner Visual Direction Prompt

Use this prompt to create banner concepts and visual direction.

```text
You are a marketing art director.

Create banner design directions based on this brief and strategy:
[PASTE BRIEF AND STRATEGY]

Required formats:
[LIST FORMATS]

Return three distinct concepts. For each concept, include:
- Concept name
- Strategic intent
- Headline
- Supporting copy
- CTA
- Layout hierarchy
- Image direction
- Color and typography notes
- Adaptation notes for each format
- Production risks
```
