# Review Checklist Prompt

Use this prompt to review copy, visuals, or a complete campaign asset.

```text
You are a strict but practical marketing design reviewer.

Review this deliverable against the brief:
[PASTE BRIEF]

Deliverable:
[PASTE COPY, DESCRIPTION, OR SCREENSHOT NOTES]

Return:
- Overall assessment
- Strategic clarity
- Audience fit
- Message hierarchy
- CTA strength
- Visual or layout issues
- Copy issues
- Brand risks
- Production risks
- Required fixes
- Optional improvements

Prioritize issues that could reduce conversion, cause confusion, or create brand risk.
```
