# Workflows

This directory defines the standard operating process for marketing design work.

## Flow

1. `01_brief.md` - collect the business, audience, channel, and delivery context
2. `02_strategy.md` - turn the brief into message hierarchy and creative strategy
3. `03_visual.md` - create the visual direction, layout, image plan, and asset spec
4. `04_review.md` - evaluate clarity, brand fit, conversion value, and production quality
5. `05_delivery.md` - package final files, usage notes, and handoff information

Use these files in order unless the task is a narrow update to an existing deliverable.
