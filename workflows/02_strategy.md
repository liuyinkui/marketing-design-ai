# 02 Strategy

## Goal

Turn the brief into a clear marketing strategy before producing copy or visuals.

## Steps

1. Identify the primary conversion goal.
2. Define the audience insight and purchase motivation.
3. Write the core message in one sentence.
4. Build the message hierarchy: headline, proof, offer, CTA.
5. Choose the visual role: explain, excite, prove, compare, or convert.
6. Select the channel approach and required deliverables.

## Strategy Output

- Objective
- Audience insight
- Core message
- Primary offer
- Supporting proof points
- CTA
- Tone of voice
- Visual direction
- Deliverable list
- Risks and assumptions

## Decision Checks

- Does the message match the audience's real motivation?
- Is the offer visible enough to understand in three seconds?
- Does the visual direction support the message instead of decorating it?
- Does each deliverable have a clear job?
