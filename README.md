# marketing-design-ai

Repository scaffold for a marketing design AI workflow.

## Structure

- `skills/` - reusable capability notes and task-specific guidance
- `workflows/` - step-by-step operating workflows
- `prompts/` - prompt assets and reusable prompt fragments
- `templates/` - reusable templates for outputs
- `examples/` - sample inputs and outputs
- `docs/` - product and process documentation
- `assets/` - supporting files such as images and references

## Getting Started

1. Add or update the skill docs in `skills/`.
2. Follow the workflow docs in `workflows/` when producing deliverables.
3. Store reusable assets and examples in the matching folders.
